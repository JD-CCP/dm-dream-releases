# DM Dream downloads

DM Dream runs a battle map on a TV for in-person tabletop RPG sessions. The GM controls it from a laptop; the TV shows only what the players should see.

This page holds the Windows installers. The app checks here for new versions when it starts.

## Install

1. Open the [latest release](https://github.com/JD-CCP/dm-dream-releases/releases/latest).
2. Download `DM-Dream-Setup-x.y.z.exe`.
3. Run it. If your browser warns about the download, choose **Keep**. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. The installer is not code-signed yet.
4. Start **DM Dream** from the desktop or Start menu.

## Update

Download the newer installer and run it over the old one. Your sessions and maps are kept.

## Requirements

Windows 10 or 11. A TV or second monitor connected by HDMI is recommended. No internet is needed once installed.
